# Portfolio site

## About
Instead of a traditional portfolio layout, the site is organized into collapsible accordion sections. This keeps the page uncluttered — you see only section titles by default, and open just the one you're interested in, rather than scrolling through everything at once.

## Sections
- **About me** — background and areas of focus
- **Projects** — an overview of ongoing and past work
- **Logs** — a running record of what's being learned or built, and why

## Features
- Accordion-based navigation (native `<details>`/`<summary>`, no JS required for the toggle itself)
- Light/dark theme switch, with the choice remembered across visits
- Custom typography (Zen Dots, Bitcount Grid Single)
- Notebook-style grid background

## Built with

Plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step. Hosted on GitHub Pages.
